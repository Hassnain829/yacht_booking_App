# Agent instructions

The project rules live in [CLAUDE.md](CLAUDE.md), and the master plan is [docs/PLAN.md](docs/PLAN.md). Follow both.

In short:

- Laravel defaults only. No Filament, Livewire or Alpine. Laravel Boost is a dev-only tool; the CLAUDE.md rules outside its guideline block take precedence.
- Ask before adding any package.
- Every form and JSON endpoint follows the security standard in CLAUDE.md.
- Work in small QA-gated steps, and never commit unless the user asks.
